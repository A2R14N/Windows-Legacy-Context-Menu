# Windows 11 Context Menu

Simple CMD scripts to switch between the **Legacy Context Menu** and the **Default Windows 11 Context Menu**.

## Usage

1. Download or clone this repository.
2. Run the desired `.cmd` file.
3. Windows Explorer will automatically restart to apply the changes.

## Scripts

| File | Description |
|---|---|
| `Set_Legacy_Context_Menu.cmd` | Restores the classic Windows 10-style context menu. |
| `Restore_Default_Context_Menu.cmd` | Restores the default Windows 11 context menu. |

## Requirements

- Windows 11
- No administrator privileges required.

## Notes

- Changes apply to the current Windows user.
- Open File Explorer windows will close during the restart.
- No system files are modified.
